🚀 Task Manager API Live

A secure REST API for managing tasks with JWT authentication

⚠️ Note: Protected routes require a Bearer token in the Authorization header. Register first to get your token.

🔐 Auth Routes

POST /api/auth/register Register a new user
POST /api/auth/login Login and get token

📝 Task Routes

GET /api/tasks 🔒 protected Get all your tasks
POST /api/tasks 🔒 protected Create a new task
GET /api/tasks/:id 🔒 protected Get a single task
PUT /api/tasks/:id 🔒 protected Update a task
DELETE /api/tasks/:id 🔒 protected Delete a task

🛠️ Tech Stack

Node.js · Express.js · MongoDB · Mongoose · JWT · bcryptjs
